# Screen audit for the new mockups

`screen-specs.json` describes the nine requested frames from the current game renderers. Use the approved Home image as the art reference; the earlier SVG layouts are not the new reference.

The default image can show Simple Mode, with advanced controls kept behind the existing mode/tab/state. Every primary visible control is specified. Conditional workflows, live prices and real user media remain replaceable in the editable SVGs and later game UI.

Important distinctions: Create produces a private 3D accessory and publication is a later Roblox flow; Avatar Lab try-ons are free; Avatar Graphics produces a 2D image with a copyable browser link; Arcade contains eleven games plus Leaderboard; Runway actions change with the real round phase. Detail density is fixed in Create and has no user picker.

This audit changed only the design specification and this note. No game code, Git delivery, asset upload or credentials were changed.
