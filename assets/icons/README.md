# Badge / product / pass icons

Circular medallion icons for every achievement badge, developer product, and
game pass, generated to match Forge UGC's in-game palette
(`src/Shared/Theme.luau`). Each is a 512×512 PNG (`png/`) with transparent
corners around an inscribed circle — Roblox crops icons to a circle in most
badge/product UI, and shipping pre-circularized art with margin means that
crop can never cut into the design. Editable source is in `svg/` (same
filenames, `.svg`).

These are upload assets for Roblox Creator Hub. Nothing in `src/` reads
these files directly or needs them at runtime — only a **badge's numeric ID**
gets pasted back into code (see below), because `AchievementService` calls
`BadgeService:AwardBadgeAsync` and needs to know which badge to award.
Developer product and game pass icons are just uploaded in Creator Hub; their
numeric IDs already live in `src/Shared/Config.luau` and don't reference the
icon file at all.

## Badges

Create each in Creator Hub → your experience → Engagement → Badges, upload
the matching PNG as its icon, then paste the badge ID Roblox gives you into
`Config.Achievements.BadgeIds` in `src/Shared/Config.luau` (currently all
`0` placeholders — a badge award is silently skipped until its ID is filled
in, everything else about the achievement, including its token reward,

## Regenerating or editing

The SVGs were generated by a small Python script (not checked into this
repo) that composes a shared circular-medallion template with a per-icon
glyph — same background gradient/gloss/ring treatment throughout, only the
accent color (from `Theme.luau`'s palette) and center glyph change. To tweak
one, hand-edit its `svg/*.svg` file directly (they're plain, readable SVG)
and re-export to PNG at 512×512 with any SVG-to-PNG tool, keeping the
transparent margin around the circle.
